# Portfólio profissional

Portfólio profissional de **Laura Marques**, estudante de Ciências da Computação, desenvolvido para a disciplina **Design Profissional** (Projeto 2: publicação do portfólio profissional e do currículo no GitHub).

## Sobre o projeto

Este projeto é uma página web simples que apresenta quem eu sou, minha formação, minhas competências, meus projetos e meus contatos. Ele foi criado com HTML5 e CSS3, sem frameworks e sem JavaScript, e é publicado gratuitamente no GitHub Pages.

O conteúdo foi escrito por mim e conferido antes da publicação. Utilizei uma IA como orientadora durante o processo, para organizar as informações e explicar o código.

## Objetivos

- Apresentar meu perfil profissional de forma clara e honesta.
- Praticar HTML5, CSS3 e organização de arquivos.
- Aprender a usar o GitHub (repositório, commits, branches e pull requests).
- Publicar um site real no GitHub Pages.

## Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo da página (`index.html`)
- **CSS3:** cores, layout e responsividade (`style.css`)
- **GitHub:** versionamento e hospedagem do código
- **GitHub Pages:** publicação do site

## Estrutura do portfólio

O site é uma página única com menu de navegação e as seguintes seções:

1. Apresentação
2. Sobre mim
3. Formação
4. Competências técnicas
5. Competências comportamentais
6. Projetos
7. Currículo
8. Contato

Organização dos arquivos:

```
portfolio-profissional/
|
|-- index.html      (página principal)
|-- style.css       (estilos)
|-- README.md       (documentação)
|-- LICENSE         (licença, se for adicionada)
|
`-- assets/
    `-- curriculo.pdf
```

## Projetos apresentados

- **Apresentação sobre Engenharia de Software** (trabalho de faculdade, em grupo): apresentação de slides sobre a área. Estudei o conteúdo e apresentei a parte sobre como se tornar engenheira de software.

## Como executar localmente

1. Baixe o projeto: no repositório do GitHub, clique em **Code** e depois em **Download ZIP**, e extraia a pasta.
2. Abra a pasta `portfolio-profissional`.
3. Dê dois cliques no arquivo `index.html` para abrir no navegador.

Não é necessário instalar nenhum programa.
